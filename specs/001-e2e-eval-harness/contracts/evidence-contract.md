# Contract: Evidence Bundle

Every run — pass or fail — produces `runs/<UTC timestamp>-<scenario-slug>/` per data-model.md.

## report.html requirements
- Self-contained single file (inline base64 thumbnails linking to the PNGs beside it).
- Ordered step list: number, party badge (agent/founder/participant/stack), name, ok/fail,
  duration; browser steps show thumbnails; protocol steps show collapsible request/response
  JSON; assert steps show expected/actual.
- Header: scenario, verdict, started-at, duration, four repo commits (dirty-flagged).
- On failure: the failing step is anchored/linked from the header and carries the page-HTML and
  console-log links.
- Generated by harness/evidence.py from transcript.jsonl alone (re-runnable: `make report
  RUN=<dir>` rebuilds it), so a crashed scenario still gets a report from whatever the
  transcript holds.

## Verdict
`verdict.json` written in a `finally:` — absence of the file means the harness itself crashed,
which is itself a reportable defect.
