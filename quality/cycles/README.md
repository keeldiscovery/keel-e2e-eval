# The cycle records (spec 079)

One file per quality cycle, written by `make quality-walk` and committed with its score files:
`<yyyymmdd>-<cloud7>.md` (the why in the founder's words, the studies, the bundles, the score files, the head, the
cost and the time, the comparison with the baseline and with the previous cycle, and a data block the other commands
read). Beside a record, `<yyyymmdd>-<cloud7>-advice.md` is `make quality-advise`'s proposals -- never applied.
Never edited by hand. The runbook is `quality/CYCLE.md`.
